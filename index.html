Personal Google Workspace integration

This is a private-use integration operated by the owner of the Estogen GitHub account. It connects a personal Hermes Agent installation to Google Workspace APIs to carry out the account owner's instructions.

The current connection requests Google Sheets access to read and update the owner's spreadsheets, including personal expense tracking. It is not a public signup service and is not affiliated with or endorsed by Google.

This website only describes the integration. It does not collect Google credentials or provide access to spreadsheets.
